# アポ管理タスク

スマートフォンでホーム画面に追加して使える、アポ・タスク管理PWAです。GitHub Pagesへのpushで自動公開します。

## GitHub Pagesで公開

1. GitHubにこのアプリのフォルダーをルートとする専用リポジトリを作成します。業務資料など、公開したくないファイルを同じリポジトリに入れないでください。
2. アプリのファイル一式（`.github`フォルダーを含む）をリポジトリにpushします。`main`または`master`ブランチへのpushでデプロイが始まります。
3. GitHubのリポジトリで **Settings > Pages** を開き、公開元を **GitHub Actions** にします。
4. **Actions** タブでデプロイ完了を確認し、表示されたPages URLをスマートフォンで開きます。

## スマートフォンに追加

- iPhone: SafariでPages URLを開き、共有メニューから「ホーム画面に追加」します。
- Android: ChromeでPages URLを開き、メニューから「アプリをインストール」または「ホーム画面に追加」を選びます。

アプリのデータは初期状態では端末内に保存されます。別端末との共有には、アプリ内「チーム」タブでSupabaseを設定してください。

## データの取り扱い

このアプリのGitHub Pages公開物にはアプリのコードが含まれます。入力データやAPIキーをコードに書き込まないでください。既存のSupabase共有SQLは認証なしで共有テーブルの読み書きを許可するため、現状のままでは共有データを機密情報として扱えません。実在する顧客情報を共有する前に、認証と適切なRow Level Securityポリシーを設定してください。
